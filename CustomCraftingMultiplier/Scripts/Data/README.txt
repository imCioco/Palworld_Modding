This folder holds files generated by CustomCraftingMultiplier.

catalog-cache.tsv       Discovered item IDs and their setting names/categories.
config.ini.bak          Previous config, kept when automatic repair changes it.
catalog-cache.tsv.bak   Previous generated catalog, kept when it changes.
*.tmp                   Temporary files used while saving; normally removed immediately.

Edit config.ini in the main mod folder, not these files.
catalog.lua in Scripts is the built-in starting list and is not generated here.
Keep this Data folder when installing or updating the mod.
